# 回声训练室 · 静态版与动态 Demo 版

打开 `index.html` 即可在桌面浏览器体验。手机浏览器和微信内置浏览器应通过 HTTPS 静态站点访问同一网址；`file://` 地址只适合本机查看。

线上全栈演示地址为 [回声训练室](https://47.239.63.61.sslip.io/)。Caddy 将根地址转发给 Fastify，由 Fastify 提供 React 页面和 API。旧演示链接会跳转到全栈首页。VPS 发布脚本位于 `deploy/fullstack-prepare.sh` 和 `deploy/fullstack-switch.sh`，真实服务验收脚本为 `deploy/fullstack-smoke.mjs`。

仓库根目录是静态版。`product/` 是动态 Demo 版，以用户手册为产品要求，以静态版为页面流程参考。动态版包含双人同步、双座位自练、亲子同机和异步留言，以及真实房间、独立身份确认、录音上传、后台语音转写和归档。复盘包含完整率、误解标签、匿名展示、报告导出和创建者的数据删除入口。

在 `product/` 中执行 `npm test` 和 `npm run test:e2e` 验证动态版。端到端测试会启动本机 PostgreSQL、Redis、对象存储和浏览器，使用模拟 AI。`npm run test:lobby` 在同一组开发容器上验证房间码和邀请入口。

静态版首页可进入同步双人、双座位自练、亲子同机、异步留言四种模拟路径。每条路径展示训练室与一轮九步：定任务 → 表达者说 → 系统划重点 → 复述者复述 → 系统对比 → 表达者标注 → 复述者澄清 → 收下建议 → 复盘归档。主题可以自定义；邀请可设置模拟有效期、四位密码和一次性使用。

复述页的示例语音可播放、暂停、继续和重播；首次音频尚未播完也能开始模拟复述，此时表达者语音自动暂停。模拟复述可暂停、续录、删除重来。系统对比按确认的要点句显示完整度、准确度、偏差类型和可澄清点，并逐条对照有问题的原话。观察者有只读动态与独立建议页；亲子同机可指定孩子担任表达者或复述者，并演示交棒和退出验证；异步留言有等待、提醒与同一留言的三种问法，示例复述结果随问法变化。同步与异步的确认页可切换模拟的两部手机，各身份只能确认自己的条目，全部确认后由表达者提交。底部复盘按四种练法显示完整率与误解类标签的逐轮变化。

复盘详情可切换匿名展示，并下载 TXT 报告；轮次详情支持模拟删除单轮或整个训练室，“我的”页面支持模拟删除全部数据，确认页会说明范围和不可恢复的正式产品要求。所有训练数据仅为当前页面的模拟状态，刷新后预置示例会恢复。录音、AI、邀请、跨设备同步和监护验证均为流程演示。示例音频为同站点提供的中文 MP3。表达录音关闭转写时可手填要点，复述提交前需要勾选转写说明。

运行 `node test-demo.mjs` 检查四种路径与主要交互。具体修正依据见 `差异审视与修正.md`；正式全栈开发的初步选型和验收顺序见 `后端技术路线与全栈实施.md`。
